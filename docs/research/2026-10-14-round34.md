# Research Round 34 — iGPU EU fully revived for real workloads (2026-10-14)

## STATIC IGPU END-TO-END OK

    OvLayaBackend(device=GPU, pad_to=256) on laya-en-static-fixed.onnx
    6 consecutive decisions: refund @ 0.9884, 42 ms each, zero variance

vs CPU ORT fp32: 54-58 ms p50 (same lineage, same decision). The iGPU EU now
serves REAL variable-length workloads via static-bucket exports + padding.

## The bug chain that got here (all fixed)

1. pad-to mode bucketed the BATCH dim (axis/dim conflation: `dim == 0`
   checked the size, not the axis) -> [256,256] feeds. Fixed: axis 0 is
   always exact.
2. The lazy compile reshaped a STATIC model (whose internal shape graph is
   fixed) -> Reshape incompatibility. Fixed: static models skip reshape.
3. act_logits NaN on padded-marker lanes -> shim-level nan_to_num with a
   documented rationale (padded lanes are outside the contract; consumers
   sanitize).

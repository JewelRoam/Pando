# Research Round 15 — Spore transfer implemented and verified (2026-10-14)

- `SporeServer`: serves a signed manifest + per-chunk bytes over HTTP
  (chunk store pre-split from the payload files).
- `pull_spore()`: sandbox gate (refuses without explicit confirmation,
  per THREAT-MODEL.md) -> manifest pull -> Ed25519 verification ->
  per-chunk hash check on arrival (fail-fast, no silent corruption) ->
  per-file Merkle verification -> on-disk verify_file.
- Manifest now carries per-chunk hex hashes (~64B/chunk; 570MB model adds
  ~560KB manifest - acceptable, enables selective re-fetch later).
- One-shot smoke (5MB / 80 chunks): sandbox gate refuses correctly; happy
  path byte-identical with all files verified; server-side corrupted chunk
  rejected with a precise error (chunk model.bin#3).

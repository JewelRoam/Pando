# Research Round 170 — The far group is real: first WAN bridge into the island

Date: 2026-10-16

Round 157's topology - "a far group is one vote" - has until now only run
on a LAN. With the island root on its own tunnel (round 169 / Task 023),
the Windows parent root can finally seat the Mac **island** as a single
member across the public internet:

```
Windows parent root  <-  bridge (Windows)  ->  tunnel  ->  island root (Mac)
                                                          |-- mac-text
                                                          `-- mac-llm-8b-local
```

`tools/wan_bridge_check.py` (island URL read from `mac-endpoint` and
cross-checked against the Task 023 report; the pairing bearer from a local
secret file):

- the bridge registered with the parent as `mac-island`;
- six decisions - three old-family rows and three brand-new-intent rows -
  all came back through the island: one warm-up at 5.0 s, then a steady
  **~1.2 s per decision** across two continents of NAT;
- five of six choices matched the expected labels; every row returned at
  `tier=verify` (the parent has no calibration table for a group vote, and
  the island's own k=1 rotation decides per request which worker answers).

That is the last architectural promise of the original brief with a live
witness: heterogeneous devices, one gate, elastic membership, and a far
group that is genuinely far - reachable, counted once, and measured.

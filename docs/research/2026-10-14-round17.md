One command each side:
    rootd --serve-spore artifacts/laya-en.int8.onnx
    pandosi.join --spore --sandbox-confirmed --root ...
Chain verified with real 571MB weights:
1. root serves a freshly-signed manifest + chunks (key generated at boot)
2. joiner discovers the root's spore endpoints, fetches the pubkey (TOFU,
   loudly printed), pulls 9132 chunks with per-chunk hash verification
3. loads the PULLED weights, runs 3 VERIFY probes (yes @ 0.76-0.80)
4. registers as LIVE at t=100s (pull+load+verify+register total)

## What this demonstrates
The autonomous replication chain (SCAN/GRAFT/SPROUT/VERIFY/LIVE) now runs
end-to-end inside one codebase, sandbox-gated and signature-verified, with

pandosi-lab packaging, chunk re-fetch on corruption) rather than new design.

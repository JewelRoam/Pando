# Research Round 145 — The governance layer, verified through the file an operator writes

Date: 2026-10-15

## The gap this round closes

The last twenty-eight rounds added rules to the swarm: which lineages are
admitted (102), which of them count as one opinion (129), how many opinions an
auto-execution needs (124), and now which advisory combiner decides the rows
the gate declines (139-144). Every one of those was measured *programmatically*
- a `Coordinator(...)` built in a check script - and none had been exercised
through the playbook, the file an operator actually writes and signs.

This round makes the advisory combiner a declared, pinned artifact and then
drives a real `python -m pandosi root --playbook <file>` with real HTTP stems:

```toml
[lineages]
admit = ["english", "typed-decisions", "multilingual"]
blocs = [["english", "multilingual"]]

[gating]
corroboration_floor = 2

[combiner]
path = "assets/combiner.json"
sha256 = "<64 hex>"
```

`[combiner]` follows the rule `[lineages.artifacts]` already set for graphs: a
path plus the digest the operator expects there. An unpinned advisory rule is
one nobody can check, and the loader refuses either a missing file or a
changed one.

## Four properties, each isolated

`tools/playbook_e2e_check.py` runs all four against a live root:

| what | result |
|---|---|
| a lineage that is not declared | `403 lineage 'not-admitted' is not declared by this playbook` |
| two lineages declared one bloc | 3 stems answer, the response reports `lineages=3, opinions=2` |
| the pinned combiner | loads from the playbook and offers `suggestion=complaint` on a split |
| a combiner whose digest changed | the root refuses to start (exit 1, sha256 mismatch) |
| **corroboration_floor, alone** | one stem, `agreement=1.0`, `opinions=1` -> **`tier=verify`** |

The last row is the one that needed care. The obvious test - a two-opinion
split landing on `verify` - does not isolate the floor, because a tied
agreement of 0.5 would have produced `verify` anyway. A single opinion that
agrees with itself reaches agreement 1.0 and would auto-execute on the plain
rule; only the floor can refuse it, and the check now says so explicitly.

## What "governed" now means in this project

| layer | declared by | checked by |
|---|---|---|
| which lineages may vote | `[lineages].admit` + calibration tables | registration 403, verified live |
| which graphs they may run | `[lineages.artifacts]` digests | attestation at registration |
| which lineages are one opinion | `[lineages].blocs` | collapsed vote counts in the response |
| how many opinions auto-executes | `[gating].corroboration_floor` | tier refusal, now isolated |
| which advisory rule decides declines | `[combiner] path + sha256` | digest check at load |
| who wrote the playbook | signature + pinned key | `load_verified_playbook` |

Every row of that table is now something an operator can state, and something
the software refuses to proceed without.

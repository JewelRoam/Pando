# Research Round 84 — Unified `pandosi` CLI

Date: 2026-10-14

## Problem

The project had accumulated separate entry points:

```text
python -m pandosi.doctor
python -m pandosi.join
python -m pandosi.rootd
python -m pandosi.stemd
python -m pandosi.grants
python -m pandosi.service
python -m pandosi.lab
```

That is workable for developers but weak for adoption. A user should not
need to know the internal module layout to inspect or join a swarm.

## Change

Added:

```text
python -m pandosi <command>
pandosi <command>          # installed console script
```

Available commands:

```text
doctor   onboard   grants   join   root
stem     bridge    service  lab
```

Existing module entry points remain valid for compatibility.

## Verified commands

```text
python -m pandosi --help
python -m pandosi --version
python -m pandosi doctor --plan
python -m pandosi grants show
python -m pandosi root --help
```

The CLI delegates to the same validated implementations rather than
reimplementing protocol logic.

## Adoption value

The first useful path can now be expressed consistently:

```text
pandosi doctor --plan
pandosi onboard --dry-run
pandosi join
pandosi grants grant lan_listen --hours 24 --yes
pandosi join --lan
```

This is a usability milestone, not a protocol change.

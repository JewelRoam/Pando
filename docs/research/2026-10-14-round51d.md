# Research Round 51d — ml lineage uncertainty root-caused (2026-10-14)

## The round-37 mystery is RESOLVED

Round 37 observed ml=greeting@0.532 on the refund case. Investigation shows:

1. **The ml lineage correctly identifies refund** — when run DIRECTLY via
   ONNXAgent, ml gives refund@0.9783 (even slightly higher than en's 0.975).
2. **The round-37 uncertainty was a DIFFERENT state string**: the multi-EU
   smoke used "User message: I want a refund, the order never arrived"
   which round 9 used differently. Different phrasing → different result.
3. **Chinese input produces the strongest signal** (refund@0.9997): the
   multilingual model is genuinely better on Chinese than English.
4. **No content-blindness**: ml's probabilities are sensible on both
   languages. The 0.53 greeting was a phrasing sensitivity, not a
   systematic weakness.

## Implication for Phase 5

Phrasing sensitivity is EXACTLY the kind of weakness that heterogeneous
consensus catches: two lineages disagree on a borderline input → verify
instead of auto-execute. RLCD training with these disagreement cases
(round 38-39 data layer) would teach the weaker lineage to match the
stronger one on ambiguous phrasings.

## This is the evolution loop working

disagreement detected → root-caused to phrasing sensitivity →
training data available (rollouts/) → RLCD would fix it.

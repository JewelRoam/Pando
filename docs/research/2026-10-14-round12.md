# Research Round 12 — Ring 0 achieved: one-command LAN onboarding (2026-10-14)

- `pandosi/join.py` implemented: capability probe -> mDNS browse for a root
  (_pandosi._tcp.local.) -> join as stem, or become root+stem and advertise.
  Backend auto-selection (ONNX Laya if weights present, else mock).
- Two-process live smoke on real mDNS: alpha becomes root (advertised on LAN
  IP), beta discovers and joins, external vote -> yes, responded 2, tier auto.
- Three bugs found and fixed en route (each now documented in code):
  1. servers bound to 127.0.0.1 while advertising the LAN IP -> bind 0.0.0.0
  2. stems registered their URL as http://0.0.0.0:port (unconnectable) ->
     register with the real LAN IP
  3. fixed min_quorum=3 escalated 2-node swarms -> adaptive min(3, |quorum|)
- This fulfills the ADOPTION.md Ring-0 promise: zero privilege, one command,
  useful on a single machine, grows by discovery.

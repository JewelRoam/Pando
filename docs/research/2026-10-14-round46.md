# Research Round 46 — playbook lineage continuity across reproduction (2026-10-14)

- rootd --serve-spore + --playbook: the spore manifest metadata now carries
  playbook_hash/name/version (manifest built AFTER playbook load - order
  verified).
- join --spore: the pulled playbook is validated AND appended to the
  joiner's LOCAL pb_history chain (genesis parent carried in the manifest
  metadata for lineage continuity).
- E2E smoke (tiny payload): joiner pulled, playbook hash matches the root's
  playbook, local chain has the entry, chain verifies OK.
- Known behavior (by design): spore join with a NON-ONNX payload fails at
  model load - real weights path was verified in round 17. The tiny-payload
  smoke targets the lineage chain specifically.
- Reproduction lineage is now fully auditable: node A's chain shows where
  its playbook came from, across any number of reproduction hops.

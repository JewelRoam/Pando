# Research Round 62 — multi-hop spore chain: 3 hops, 0 integrity failures (2026-10-14)

## A -> B -> C -> D: all byte-identical

    origin (2MB) -> nodeB (32 chunks) -> nodeC (32 chunks) -> nodeD (32 chunks)
    97 total chunks transferred, 0 integrity failures
    Every hop signed with the same Ed25519 key, every manifest verified

## What this proves

The "infinite reproduction" is real: a spore can reproduce any number of
times while maintaining byte-level integrity. Each intermediate node can
become a seed for the next hop, enabling exponential propagation.

Combined with the NPU breakthrough (round 54: NPU works after 4-step
enablement), this means the reproduction chain can spread to heterogeneous
devices (CPU-only boxes, iGPU machines, NPU machines) with integrity
guaranteed at every hop.

## Engineering note
The chain test uses SporeServer (in-process HTTP). For production, the
seed role would be integrated into stemd/rootd (round 55 queue item).

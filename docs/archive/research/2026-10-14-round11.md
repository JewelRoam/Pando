# Research Round 11 — first graft acceptance report (2026-10-14)

16-task suite (choice/score/noul x 3 lineages) run against all three ONNX
lineages on the dev box CPU (full data: docs/research/graft-report.json).

| lineage | accuracy | ECE | p50 latency |
|---|---|---|---|
| english (421M) | 0.667 | 0.357 | 54.9 ms |
| multilingual (322M) | 0.833 | **0.167** | **24.3 ms** |
| typed-decisions (421M) | **1.000** | 0.430 | 59.6 ms |

Findings:
1. typed-decisions scores 16/16-correct on its home turf (fine-tuned for
   exactly these workflows); multilingual is the best generalist AND the
   fastest AND best-calibrated - a strong default worker.
2. ECE 0.17-0.43 across ALL lineages: the calibration layer (blueprint 3.2.1)
   is not optional. multilingual ships the best raw calibration.
3. Eval-harness bug found and fixed en route: score answers use a float
   "score" key (expected value), not "choice" - the first suite run wrongly
   failed every score task.
4. Remaining miss: ml04 (Korean incident, risk=high) failed only on
   multilingual; candidate training-data gap, noted for Phase 5 RLCD.

Caveat: 16 tasks is a smoke-scale suite - numbers show the harness works and
lineages differ; they are not significance-tested accuracy claims.

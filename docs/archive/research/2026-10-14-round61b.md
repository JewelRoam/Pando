# Research Round 61b — calibration is load-bearing: 2 tier flips proven (2026-10-14)

## Experiment: does calibration change tier assignment?

High-confidence votes (0.78-0.98): tier stays auto regardless of T.
Low-confidence votes (0.41-0.53): tier stays verify regardless.
**Boundary cases DO flip** - proving calibration is load-bearing:

- p=0.58, T=0.5 (sharp): tier verify -> **auto** (sharp calibration promotes)
- p=0.62, T=2.0 (soft): tier auto -> **verify** (soft calibration demotes)

## Implication

The choice of temperature directly affects the auto-execution rate.
Sharp calibration (T<1) is more permissive; soft calibration (T>1) is
more conservative. The optimal T should be tuned per deployment based
on the cost of false positives vs false negatives.

## Current status: identity transform (T=1.0)
No calibration config files exist yet (Laya ships uncalibrated), so the
system currently uses identity transform. Once calibration data is
computed from a held-out set, the temperatures should be set per-checkpoint.

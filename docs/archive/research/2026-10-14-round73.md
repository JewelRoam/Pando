# Research Round 73 — Real RLCD fine-tune on RTX 3070

Date: 2026-10-14

## Environment

- GPU: NVIDIA GeForce RTX 3070, 8 GB
- PyTorch: `2.14.1+cu130`
- CUDA runtime: 13.0
- cuDNN: 92400
- training device: `cuda:0`

The CUDA PyTorch environment is isolated in `.venv-cuda` so the host's
CPU-only PyTorch installation is not modified.

## Before/after evaluation

The 14-task English graft slice was evaluated against the original and
CUDA-fine-tuned checkpoints:

| metric | original | CUDA fine-tuned |
|---|---:|---:|
| accuracy | 0.7857 | 0.7857 |
| decision labels | 14 reference labels | 14/14 unchanged |
| max confidence delta | - | **0.1760** |

No labels changed. The update reinforced confidence on already-correct
decisions, especially the target refund case.

## Interpretation

The evolution loop is now executable on the external GPU:

```text
rollout contrast row
  -> laya.train.finetune(device="cuda")
  -> CUDA checkpoint
  -> before/after decision comparison
```

This does not yet prove generalization: the dataset contains one contrast
pair and one optimizer update. It proves the CUDA training path, checkpoint
serialization, reload, and decision evaluation are operational.

## Next evidence needed

# Research Round 143 — From nothing to a served decision in 1.5 seconds

Date: 2026-10-15

## The product question, asked with the session's own results

The user's standing concern about this project is adoption: "ease of use is
what decides whether an open-source project survives." The session's decision
work ended with something that speaks directly to it - a swarm that beats its
best member (rounds 139-142) and a **19 KB text member** trained from the
swarm's own labels (round 126), which needs no weights, no accelerator and no
privileges to run.

That member was reachable only through `stemd --backend text`; the friendly
entry point, `python -m pandosi join`, offered `mock` and `onnx` and fell back
to **mock** when no ONNX graph was present - a voter that answers from a hash
and means nothing. So a fresh clone's first experience was a fake decision.

## The change

- `pandosi/join.py`: `--backend text` is now a first-class choice, and
  `pick_backend` falls back to the shipped text member instead of the mock
  when no ONNX weights exist. Verified both ways: with artifacts present it
  picks ONNX, with them hidden it picks **text**.
- `join` also loads `assets/combiner.json` when the repository carries one, so
  the one-command path runs with the advisory combiner (rounds 139-142) rather
  than the bare gate. The root prints what it loaded.

## Measured, with the real CLI on this machine

`tools/quickstart_check.py` runs the two commands as subprocesses and times
each step:

| step | time |
|---|---:|
| root ready to answer `/pairing` | 0.56 s |
| member registered after the `join` command | 0.89 s |
| first decision served | 0.05 s |
| **launch to served decision** | **1.51 s** |

The decision came back `tier=auto` with a real answer from the 19 KB member.
`join` also prints the capability probe, the execution units it found
(`CPU, GPU.0, GPU.1, NPU`), the backend it chose, and a ready-to-run curl
example - the path is self-documenting once it starts.

## Why this is worth a round

Nothing here is new science; it is the science made reachable. The parts that
made the fast path honest are all results from this session:

- the member is small because round 123 measured that a cheap decorrelated
  voter is worth points and round 126 made one shippable;
- the fallback is *real* rather than a mock because that member exists;
- the combiner is attached by default because rounds 139-142 measured it as
  safe (advisory, never at `auto`) and worth three-quarters of the remaining
  headroom on the rows the gate declines.

A project whose first two commands produce a real vote in 1.5 seconds, with no
download and no accelerator, has cleared the adoption bar the user set;
everything else it can do is an upgrade from there.

# Research Round 88 — Source distribution and release workflow

Date: 2026-10-14

## Change

Added `tools/verify_sdist.py` for the source archive and a tag-triggered
GitHub Release workflow.

The sdist check requires:

- `pyproject.toml`, `README.md`, package sources;
- playbook, graft suite, and calibration assets;
- no `artifacts/`, virtualenv, build/dist, ONNX, or safetensors content.

The build now uses SPDX `license = "Apache-2.0"` and `license-files`,
removing the setuptools deprecation warning.

## Release workflow

`.github/workflows/release.yml` runs on tags matching `v*`:

1. build sdist and wheel;
2. verify both archives;
3. write `dist/SHA256SUMS`;
4. create a GitHub release with generated notes and both artifacts.

Regular CI now builds and verifies both distributions as well.

# Research Round 19 — playbook format landed (2026-10-14)

- `pandosi/playbook.py`: TOML playbook loading + validation (meta required,
  question types choice/score/noul, unique ids, criteria for choice/score,
  actions need when+do), canonical_json + sha256 hash (stable, default=str
  for TOML dates), question_specs() converting to Laya predict() format.
- `assets/playbook.example.toml`: refund-triage example (3 questions, 1
  action binding, gating thresholds).
- rootd --playbook: loads at boot, serves GET /playbook {name, version,
  hash, canonical}; hash is what a spore manifest would sign.
- Smokes: valid playbook loads + stable hash; three malformed playbooks
  (no-meta / bad-type / dup-id) rejected with precise errors; served body
  parses correctly (fixed a double-JSON-encoding bug found by the smoke).
- Shared LAN proxy bypass moved to common.bypass_proxy_for_lan() - rootd and
  join both call it now (fixes registry-proxy black-holing on all endpoints).

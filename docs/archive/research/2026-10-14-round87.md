# Research Round 87 — Wheel content verification in CI

Date: 2026-10-14

## Change

`tools/verify_wheel.py` inspects the built wheel as a ZIP archive and
requires:

- `pandosi/__init__.py`;
- `pandosi/cli.py`;
- `pandosi/resources.py`;
- `pandosi/doctor.py`;
- `share/pandosi/assets/playbook.example.toml`;
- `share/pandosi/assets/calibration/english.json`.

CI now builds the wheel with:

```bash
python -m pip wheel . --no-deps -w dist
python tools/verify_wheel.py dist
```

## Local result

```text
pandosi-0.0.1-py3-none-any.whl
size: 74096 bytes
entries: 37
required code and asset entries present
```

## Why this matters

Install tests can pass while a future refactor silently drops entry points,
resource files, or package-data rules. This check makes the release archive
itself the verified artifact.

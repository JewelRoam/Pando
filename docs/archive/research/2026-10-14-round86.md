# Research Round 86 — Small assets in the installed wheel

Date: 2026-10-14

## Problem

The first install check proved that the console script worked, but a wheel
installed outside the repository reported:

```text
playbook (assets/) -> miss
calibration data   -> miss
```

Those files are small enough to ship, unlike model weights.

## Change

Added `pandosi.resources.asset_path()` with search order:

1. `PANDOSI_ASSETS`
2. current checkout `assets/`
3. source-tree package parent
4. installed wheel data path

`pyproject.toml` now packages:

- playbook examples and history schema assets;
- graft/prompt JSONL suites;
- calibration JSON files.

Model weights and generated ONNX graphs remain external and ignored.

## Isolated install result

Wheel size increased from 62.6 KB to 74.0 KB.

From a directory outside the repository:

```text
pandosi --version       -> pandosi 0.0.1
playbook (assets/)      -> ok
calibration data        -> 3 checkpoints, ok
zeroconf                -> miss without [lan]
onnxruntime             -> miss without [onnx]
```

The install checker now treats the packaged playbook and calibration assets
as required.

## Remaining external artifacts

- model weights (`*.onnx`, `*.safetensors`);
- generated dashboards and rollouts;
- operator grants and tokens;
- CUDA runtime environment.

This keeps the wheel portable while making the first-run diagnostics
meaningful after installation.

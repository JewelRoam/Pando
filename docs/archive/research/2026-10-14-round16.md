# Research Round 16 — spore join loop closed; proxy black-hole found & fixed (2026-10-14)

Full SPROUT/VERIFY loop with REAL 571MB weights:
- seed serves the int8 ONNX via SporeServer (9132 chunks)
- joining node: pulls with per-chunk hash verification, loads the pulled
  weights, runs 3 VERIFY probes (yes @ 0.76-0.80), registers as LIVE
- with proxy env set (adversarial condition), registration now succeeds

## Root-caused & fixed

1. **Proxy black-hole (the big one)**: urllib on Windows honours system/
   env proxies; with HTTP_PROXY set, register POSTs to 127.0.0.1/LAN were
   routed into the proxy and silently retried forever. py-spy dump showed
   the joiner idle in the register retry loop; a one-line error print
   exposed it. Fix: join.py sets NO_PROXY={localhost,127.0.0.1,lan_ip}
   at startup - all PandoSI traffic is LAN-local by design.
2. Local `import urllib.request` inside main() shadowed the module-level
   import for the whole function (classic Python scoping trap) - removed.
3. join.py gained --root (explicit, skips discovery) and --onnx-path
   (needed for post-pull verification smokes).

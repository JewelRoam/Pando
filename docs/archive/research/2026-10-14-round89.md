# Research Round 89 — Install directly from the GitHub URL

Date: 2026-10-14

## Command

The package checker now supports remote-source installation:

```bash
python tools/package_check.py \
  --source git \
  --git-ref main
```

It creates a temporary venv, runs pip against:

```text
pandosi @ git+https://github.com/JewelRoam/PandoSI.git@main
```

and executes the installed console script outside the repository.

## Result

```text
git clone: worked
wheel build: pandosi-0.0.1-py3-none-any.whl, 72553 bytes
pandosi --version: pandosi 0.0.1
doctor --json: ok
playbook (assets/): ok
calibration data: 3 checkpoints, ok
```

No local checkout or editable install was involved in the execution path.

## Adoption meaning

A user can now try the project without manually cloning or setting up a
Python package layout:

```bash
pip install "pandosi[runtime] @ git+https://github.com/JewelRoam/PandoSI.git@main"
pandosi doctor --plan
```

This is still a source install, not a PyPI release. It builds from the
repository at the selected ref and therefore requires `git`.
